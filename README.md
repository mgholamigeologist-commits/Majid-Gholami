# Geologist Assistance

A lightweight field geology helper for quick rock type interpretation, sample logging, and basic decision support.

## Features
- Sample entry form for location, mineralogy, texture, hardness, and notes
- First-pass rock classification: igneous, sedimentary, or metamorphic
- Confidence estimate and suggested field actions
- Simple local sample log for repeated field use

## Run locally
Open `index.html` directly in a browser, or serve the folder with:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project purpose
This project is designed as a useful starter kit for geologists, students, or field crews who need a clean way to record observations and generate a quick interpretation before more detailed lab work.
